# CodeAlpha Internship Tasks Repository

Welcome to the **CodeAlpha Internship** projects repository. This monorepo contains modern, production-ready web applications built with Next.js, React, TypeScript, and Tailwind CSS.

## 🚀 Running the Projects

### 1. E-Commerce Store (Task 1)
```bash
cd ecommerce-store
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the store.

For production build & linting:
```bash
npm run lint
npm run build
npm run start
```

### 2. Project Management Tool
```bash
cd project-management-tool
npm install
npm run dev
```
